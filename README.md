# Snake Water Gun Game 🐍💧🔫

A simple command-line Snake Water Gun game built with Python.

## Features

- 🎮 5-round match system
- 🎲 Random computer choices
- 🏆 Score tracking
- 🔄 Play again option
- ✅ Input validation
- 🤝 Draw handling

## Rules

- 🐍 Snake beats Water
- 💧 Water beats Gun
- 🔫 Gun beats Snake
- Same choices result in a draw

## How to Run

1. Clone the repository:

    git clone https://github.com/Navaneet-Upadhyay/snake-water-gun-game.git

2. Open the project folder:

    cd snake-water-gun-game

3. Run the game:

    python main.py
